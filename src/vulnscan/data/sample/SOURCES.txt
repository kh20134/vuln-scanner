표본 데이터 출처
================

이 디렉터리의 파일은 테스트와 오프라인 시연을 위한 작은 표본이다. 전체 데이터베이스가 아니다.

nvd-sample.json
  NVD CVE API 2.0 https://services.nvd.nist.gov/rest/json/cves/2.0
  각 CVE를 cveId 매개변수로 개별 조회한 응답에서 구성(configurations), CVSS, weaknesses,
  영문 description만 남겼다. references, 비영어 설명, Red Hat affected(VEX) 블록, matchCriteriaId는 제거했다.
  조회 시점의 lastModified 값은 레코드 안에 그대로 있다.
  This product uses data from the NVD API but is not endorsed or certified by the NVD.

cwec-sample.xml
  MITRE CWE 4.20 (cwec_v4.20.xml, 2026-04-30)
  https://cwe.mitre.org/data/xml/cwec_latest.xml.zip
  Copyright (c) The MITRE Corporation. CWE is a trademark of The MITRE Corporation.
  선택한 Weakness의 ID, Name, Abstraction, Status, Description만 발췌했다.
  이용조건: https://cwe.mitre.org/about/termsofuse.html

kev-sample.json
  CISA Known Exploited Vulnerabilities catalog
  https://www.cisa.gov/sites/default/files/feeds/known_exploited_vulnerabilities.json
  표본 CVE에 해당하는 항목만 남겼다. dateReleased는 원본 카탈로그 값이다.

epss-sample.json
  FIRST EPSS API https://api.first.org/data/v1/epss
  표본 CVE 10건을 한 번에 조회한 응답이다.
